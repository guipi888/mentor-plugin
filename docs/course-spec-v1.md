# 课程脚本规范 v1

> 导师 Mentor · course-spec v1.0 · 2026-10-20

## 1. 概述

课程脚本是一个 JSON 文件，描述「教用户学会某个网页应用」的完整步骤序列。跟学渲染引擎按脚本逐步高亮页面元素并展示讲解；创作模式产出的就是这个格式的文件。

## 2. 文件结构

```json
{
  "site": "网站名称",
  "url_pattern": "URL 匹配规则",
  "version": "1.0",
  "created": "2026-10-20",
  "steps": [
    {
      "id": 1,
      "selector": "CSS 选择器",
      "fallback_text": "兜底文本",
      "title": "步骤标题",
      "content": "讲解内容",
      "advance": "manual"
    }
  ]
}
```

## 3. 顶层字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| site | 是 | 课程名称，显示在插件课程列表 |
| url_pattern | 是 | URL 匹配规则，如 `https://www.example.com/*`，仅作记录用途（MVP 阶段不强制校验） |
| version | 否 | 课程版本，站点改版后可递增 |
| created | 否 | 创建日期 |
| steps | 是 | 步骤数组，至少 1 步 |

## 4. 步骤字段说明

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| id | 是 | — | 步骤序号，从 1 开始连续递增 |
| selector | 是 | — | CSS 选择器，指向要高亮的目标元素 |
| fallback_text | 否 | 空 | 兜底文本：selector 失效时，引擎查找文本完全匹配的可点击元素 |
| title | 是 | — | 步骤标题，一句话说明这一步讲什么 |
| content | 是 | — | 讲解内容，告诉用户这个区域/按钮是干嘛的、能实现什么 |
| advance | 否 | manual | 推进方式：`manual`（用户点「下一步」）或 `auto`（用户点击目标元素后自动推进） |

## 5. selector 生成规则

引擎内置自动生成，创作时无需手写。生成优先级：

1. 元素有 `id`：`#id`
2. 元素有 class 且组合唯一：`tag.class1.class2`
3. 结构路径：`body > div:nth-child(2) > ul > li:nth-child(3)`
4. 结构路径不唯一时，尝试 `aria-label` 属性选择器

**选择器唯一性要求**：`document.querySelectorAll(selector).length === 1`，否则该步骤在跟学时可能高亮错误元素。

## 6. fallback_text 使用

站点改版导致 selector 失效时，引擎用 fallback_text 兜底：先查找页面上**文本完全相等**且可见的元素；找不到时退化为**文本包含**匹配（如按钮文字变成「新建图文消息」，fallback_text 填「新建图文」仍可命中）。两种匹配都取文本最短的元素，避免误中父级容器。建议对关键步骤填写，如「图文素材」「保存并群发」。

## 7. advance 推进方式选择

| 方式 | 适用场景 |
|---|---|
| manual | 讲解型步骤：只让用户认识界面，不需要操作 |
| auto | 操作型步骤：用户必须点击该元素才能继续，适合关键路径教学（点完自动进下一步） |

## 8. 创作流程指南

1. 打开目标网站并登录，点插件图标 → 「创作模式」
2. 鼠标移到目标元素上（虚线高亮），单击选中（实线高亮），selector 自动填入编辑器
3. 填写步骤标题、讲解内容，选择推进方式，点「添加步骤」
4. 重复 2-3，完成后点「保存课程」（存本地）或「导出 JSON」（分享给他人）
5. 建议：先完整走一遍真实操作动线，再倒推设计步骤拆分
