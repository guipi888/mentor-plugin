# 导师 Mentor

开源网页教学引导引擎：在真实网页上分步高亮，手把手教会用户任何网页应用。

- 引擎 MIT 开源，课程脚本由社区按规范创作
- 跟学期零网络请求、零 token 消耗（纯本地 DOM 操作）
- 当前版本：v0.1.2（内置「公众号后台入门」课程，tooltip 四向避让）

## 1. 目录结构

```
mentor-plugin/
├── manifest.json            # MV3 插件清单（当前匹配 mp.weixin.qq.com）
├── background.js            # service worker：存储初始化、内置课程加载、步骤徽标
├── content/
│   ├── content.js           # 核心：跟学渲染引擎 + 创作模式
│   └── content.css          # overlay 样式（浅色主题）
├── popup/
│   ├── popup.html           # 工具栏弹窗
│   └── popup.js             # 课程列表、开始/导入/导出/创作开关
├── courses/
│   └── gzh-basic.json       # 内置示例课程：公众号后台入门（8 步，安装即用）
├── docs/
│   └── course-spec-v1.md    # 课程脚本规范 v1（创作者必读）
└── README.md
```

## 2. 安装（Chrome / Edge）

1. 地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `mentor-plugin` 目录
4. 工具栏出现橙色「导」字图标即安装成功

## 3. 使用

### 3.1 跟学（用户）

1. 打开并登录公众号后台 <https://mp.weixin.qq.com>
2. 点工具栏插件图标 → 课程列表 → 「公众号后台入门：从登录到发出第一篇文章」→「开始」
3. 按页面高亮提示操作：阅读讲解 → 点「下一步」推进
4. 随时可点「退出」结束课程

### 3.2 创作（课程作者）

1. 打开目标网站并登录
2. 点插件图标 → 「创作模式」
3. 鼠标悬停目标元素（虚线）→ 单击选中（实线）→ selector 自动填入
4. 填写标题、讲解、推进方式 → 「添加步骤」
5. 「保存课程」存本地，或「导出 JSON」分享

### 3.3 导入导出

- 导出：插件弹窗 → 「导出课程」→ 下载 JSON 文件
- 导入：插件弹窗 → 「导入课程」→ 选择 JSON 文件
- 与他人共享课程 = 互传 JSON 文件

## 4. 课程脚本规范

创作者必读 `docs/course-spec-v1.md`。核心：一步 = {指向哪个元素，说什么}。

## 5. 如何添加新网站支持

当前版本默认只对公众号后台（mp.weixin.qq.com）生效。要给其他网站做课程，两处加上域名（以飞书为例）：

1. `manifest.json` 的 `host_permissions` 加：`"*://*.feishu.cn/*"`
2. `manifest.json` 的 `content_scripts[0].matches` 加：`"*://*.feishu.cn/*"`

改完回 `chrome://extensions` 点插件卡片上的刷新图标即可。

## 6. 当前限制（MVP）

- 仅覆盖 Chrome / Edge 的 MV3 扩展
- 课程与站点匹配靠人工（url_pattern 仅作记录，不强制校验）
- 内置课程的 selector 为占位框架，fallback_text 兜底（先精确后包含匹配）；公众号后台改版后需用创作模式重新校准
- 课程市场（上传/下载/评分）未做，验证后接入原点工具站
- 桌面软件（VS Code 桌面版、PS 等）不在覆盖范围，属后续阶段

## 7. 技术栈

Manifest V3 · 原生 JS · chrome.storage.local · 无第三方依赖
